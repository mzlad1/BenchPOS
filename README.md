# BenchPOS - Shop Billing & Inventory Management System

**BenchPOS** is a modern, offline-ready point-of-sale and inventory management system built with **Electron.js**. It provides comprehensive business management tools for retail operations, supporting multi-device synchronization and seamless offline functionality.

---

## 🚀 Features

### 💰 Sales & Billing
- **Point of Sale Interface**: Intuitive sales processing with barcode scanning
- **Invoice Management**: Create, edit, and track customer invoices
- **Receipt Generation**: Professional receipt printing with customizable templates
- **Returns & Refunds**: Handle full or partial returns with inventory adjustments

### 📦 Inventory Management
- **Product Catalog**: SKU-based product tracking and management
- **Stock Levels**: Real-time inventory tracking with low-stock alerts
- **Categories & Pricing**: Organize products and apply flexible pricing rules
- **Import/Export**: Manage inventory in bulk via CSV
- **Inventory Reports**: Detailed insights and valuation metrics

### 👥 User Management
- **Multi-User Support**: Role-based access (Admin, Manager, Cashier)
- **User Permissions**: Set granular permissions per role
- **Activity Logging**: Track system actions and user activity
- **Secure Authentication**: Firebase-based login and identity handling

### 📊 Reporting & Analytics
- **Sales Reports**: Visualize daily, weekly, and monthly performance
- **Inventory Reports**: Track stock movement, levels, and valuation
- **Dashboard**: Real-time KPIs and performance metrics
- **Export Options**: Generate reports in PDF and CSV formats

### 🔄 Synchronization & Backup
- **Offline Mode**: Operate fully without an internet connection
- **Data Sync**: Automatic synchronization when online
- **Multi-Device Support**: Consistent access across devices

---

## 🛠️ Technology Stack

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Backend**: Electron.js, Node.js
- **Database**: Firebase Firestore with local fallback
- **Authentication**: Firebase Authentication
- **Charts**: Chart.js for visual reporting
- **Styling**: Custom CSS with responsive design principles
